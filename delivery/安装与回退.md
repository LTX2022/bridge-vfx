# 安装与回退

此 ZIP 是候选快照，不会自动安装、覆盖桌面主工程或修改 Houdini/Nuke/WorkBuddy 配置。

## 使用候选源码

1. 将 `bridge-skills/` 解压到新的独立目录，保留现有主工程与安装目录。
2. 按 `bridge-skills/README.md` 和相应 skill 的安装说明执行人工评估；安装前先备份目标目录与其状态目录。
3. 本包的 unittest 与 software backend 证据不构成真实 DCC 安装或运行授权。

## 回退

1. 停止使用本候选目录。
2. 恢复安装前备份的文件与状态目录；不要把候选的 state/ledger 与旧版本混用。
3. 若尚未安装，删除新解压的候选目录即可；原始输入包单独保留在 `input/`。
