# Bridge C1–C6 软件候选

包内 `bridge-skills/` 是完整源码候选；`input/` 保存未经改写的输入 ZIP；`changes.patch` 记录输入源码与候选快照的差异；`evidence/` 保存逐组前后证据与校验脚本输出。

在 `bridge-skills/` 根目录使用 Python 3.11 运行标准套件：

```sh
/opt/homebrew/bin/python3.11 tests/run_tests.py
```

使用 `delivery/verify_delivery.py` 校验 ZIP CRC、UTF-8 文件名、路径安全、符号链接、文件清单哈希，以及 changes.patch 的正向/反向逐文件重建。运行真实 DCC、模型或发布检查不属于本包的测试路径。
