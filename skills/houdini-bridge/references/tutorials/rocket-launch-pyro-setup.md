## 核心工作流(教程三段式)

```
① 源(Source): 几何 -> 撒点 -> 加点属性(temperature/density/vel)
② 模拟(Pyro Solver): 点属性 -> 体积场 -> 容器内解算
③ 缓存(File Cache): 按需导出字段(删多余字段省磁盘)
```

## 分步要点(带视频时间戳)

### ① 源的创建(0:00-12:00)

| 步骤 | 要点 | 还原的真实术语 |
|---|---|---|
| 1 | 球体 1m 半径(直径 2m)做发射源演示 | sphere |
| 2 | **Source 节点**(H18+)撒点:Total Count 控制数量;粒子间距 0.1(更密)/0.5 | Source / Total Count |
| 3 | 撒点位置三选一:表面 / 内部 / 表面+内部;教程选**内部**更均匀 | Surface Scatter / Scatter In Volume |
| 4 | 给点加属性:temperature + density(点属性,不是场) | Point Attributes |
| 5 | **VolumeSource 把点属性转成体积场**;源的温度/密度场质量跟随模拟 Division | Volume Source DOP |

**原理讲解**(教程最有价值的部分,5-11 分钟):
- 体素(voxel)= 3D 网格的格子,所有场信息存在体素里
- **密度 = 烟的浓度**(体素值 0-1,决定透明度)
- **温度驱动浮力**:热烟上升(现实世界烟雾因温度高于空气而上升),没温度的烟永远静止
- 演示容器 25×25×25 = 15625 体素,其中活动体素 8729(有 density/temperature 的)

### ② 容器与模拟设置(12:00-45:00)

| 设置 | 值 | 说明 |
|---|---|---|
| 容器尺寸 | 2×2×2 起步,向上扩展到 10 高 | 烟会去哪就给哪留空间 |
| 容器扩展 | 参考场选 **density**,自动跟随烟雾生长 | 自动扩容 |
| Padding | 各轴 +2 | 模拟边缘与容器边缘的安全距离,防切烟 |
| 初始帧初始化 | 开启 | 第一帧只初始化不模拟,防首帧卡死;设大参数时先关模拟再开 |
| **Division Size** | 0.2 -> 0.1 | ⭐ 模拟质量核心参数 |
| Substeps | min/max 自适应(快速运动自动加步) | 移动快导致蘑菇形态失真时加步 |
| Time Scale | 可动画(如 2 -> 1.05) | 控制形成快/运动慢的节奏感 |

**Division Size 的代价**(20-30 分钟,重要数字):
- 0.2 -> 0.1(减半):体素数不是 ×2 而是 **×6**(46,045 -> ~238,000,立方关系)
- 源的 Division 会**自动继承**模拟的值(源质量匹配模拟质量)
- 分辨率越高模拟越慢,但细节越好;看到"十字线条/方块感"就是分辨率不足,降 Division(如 0.2->0.05 演示)

### ③ 力与形态细节(30:00-55:00)

| 参数 | 作用 | 教程值 |
|---|---|---|
| vel(点属性) | 初始速度向量(如 (1,0,0) 向 +X 推烟),与温度浮力叠加 | (1,0,0) 演示对角线上升 |
| **Dissipation 耗散** | 烟随时间消失;0.9=90% 快速消失变透明 | 0.1(慢)/0.9(快)对比 |
| **Disturbance 扰动** | 表面小触手/条纹细节;块大小 0.05-0.2 | 起伏表面细碎感 |
| **Turbulence 湍流** | 模拟真空缺失的空气扰动;速度阈值 0.15(只在运动处起效) | swirl size 0.5/0.1 对比 |
| 温度控制扰动 | 按温度范围激活(冷区不扰动) | 温度下降后激活 |
| Cooling Rate 冷却 | 温度扩散/消散速度 | 与 dissipation 区分 |
| 浮力方向 | 默认 +Y;可改任意轴(如 X=侧向浮力) | 演示旋转 90 度 |

**可视化模式**(35-40 分钟):速度(红=快蓝=慢)/温度/密度,分通道查看,湍流有独立可视化。

### ④ 缓存与字段导出(55:00-68:36)

| 要点 | 说明 |
|---|---|
| 开启缓存写盘 | 模拟自动写磁盘;自动缓存(Autocache)+ File Cache 节点 |

## 参数速查(还原后)

```
Source:              Total Count / 粒子间距 0.1 / 内部撒点
点属性:              temperature + density (+ vel 初始速度)

```
