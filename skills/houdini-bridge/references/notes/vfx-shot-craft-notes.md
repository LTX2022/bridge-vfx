## 1. 特效镜头的细分（难度分级）

| 级别 | 定义 | 例子 |
|---|---|---|
| S 类 | 世上没发生过、无参考，全靠想象创造的超高难度镜头 | 两颗内行星相撞 |
| A 类 | 有参照、可用物理公式算运动速度，但技术实现复杂 | — |

## 2. 镜头注意事项（用户审美方法论）

### 总原则

- 拿到镜头先**符合叙事逻辑**，再从自己审美出发二次创造——看似真实未必真实，
  但要合逻辑、质感有发挥。
- **特效要亲近情感**。三要素：**材质、动态、造型**；
  再看光感、造型、"乱"和"散"的区别、元素层次与节奏。
- glow 做法：第一层加强核心，第二层在外面做大光晕。
- **抓住参考的特征**；细节！细节！细节！层次！层次！层次！
- 注意背景故事（衣服污渍是怎么来的），画面才自然。
- 卡通片经验：张嘴镜头里牙齿/舌头/口腔内壁要稍微提亮——CG 反弹次数有限，
  口腔小补不进光容易死黑（常见反馈：口腔太黑/头发太黑/眼珠子太黑）。
- 相机抖动做不好：跟踪参考片里的相机抖动，应用到自己的相机上。

### 层次（用户反复强调的核心）

- 用**点线面、元素搭配（大中小/强中弱）、明暗、虚实、景深**分层次，
  不要均匀，要有区分度。明暗虚实能做出细节和精度做不到的层次。
- 节奏：闪可能就 2、3 帧，快的地方 10 帧，慢的地方 40 甚至 70 帧再慢慢消散；
  爆炸要控制好黑白闪、节奏感冲击感。每个元素的造型都要独特。
- 点线面占比与作用的工作流：
  1. 拿到参考/概念稿，拆解客户需求——**美术是 1→100，技术只管 0→1**；
     把参考拆成一层层，周期和效果心里才有底。
  2. 不要让客户"抽奖"：要看到点上；技术越简单高效越好，美术要持续提升。
  3. 不要为了做而做：不知道怎么做不可怕，可怕的是不知道哪里不好、缺什么；
     **一定要知道什么是不要做的**。
- 明暗对比法：亮暗亮 / 暗亮暗交替产生层次（不一定要黑，比原先暗、能区分即可；
  例：深红衬前景花瓣；暗底要虚、纹理别太清晰，**注意亮边**）。
  截图见原笔记 QQ20250418 系列。

### 合成细节 / 色彩质感

- 匹配参考时逐项核对：阴影柔和度、阴影深度、暗部深度、景深、曝光、色调变化、
  表面瑕疵、纹理大小、清晰度。
- 冷色环境里，同颜色会显暖；**想突出某颜色，在它旁边放灰色**。
- 高光饱和度相对暗光较低——合成做高光时稍微降一点高光饱和度更真。
- 没细节的亮部材质（如书本）：直接拉亮度没质感，用亮度键（Nuke `keyer`）
  提取纤维细节，再和拉亮部分做遮罩合成。
- 不同材质对不同光线的反射不同；黑色物体和白色物体反射光量不同——结合参考做。
- "藏色"：做一个颜色的东西不代表只有这个颜色；在结构转折处掺轻微色相变化，
  哪怕没打光也要用明暗/色相/饱和度"调出"灯光效果。适合魔法光效、特殊材质。
- 色彩质感三抓手：**色相、明暗、虚实**（虚实可强调空间关系）。

## 3. 特效思路（实拍结合类案例）

### 草地结合实拍

模型要融进草地素材：在模型前面种一些草，渲染成遮罩，给模型底部做草的遮挡。

### 骨折镜头（实拍+合成方案）

1. 找像骨头材质的道具（案例：大葱沾血 + 贴皮肤质感的橡胶假人皮套）。
2. 拍 3 个镜头（道具和手臂都要贴跟踪点）：
   - 道具折断镜头（抠出做前景）；
   - 手臂镜头（中间层，抠出手臂）；
   - 空背景镜头（最底层，方便合成）。
3. 跟踪手臂上的点，数据放空对象，道具父子级连到手臂上。
4. 抠出折断的道具，把手臂分两部分，旋转折断那截。
5. 新手臂图层用 `CC Bend It` 或 `边角定位` 填充弯曲处，`Alpha 遮罩` 单独提取。
   截图见原笔记 QQ 截图 20240703 系列。

### 屏幕反射

拍摄时屏幕绿幕后方架 2 台三脚架 GoPro，以防后期想要演员在镜面上的反射而主机位拍不到。
细微细节显著增强真实感。

### VHS 效果

- 《电幻国度》正宗方案：合成视频录到老式 VHS 磁带再采回来——
  视频降频 → USB → 媒体播放器 AV 输入录像机 → 录到磁带转模拟 →
  采集卡接录像机输出回采为数字文件 → 最后检查 + 音频做旧。
- 免费插件：`NTSC-RS`（基于复合视频模拟器算法，模拟 NTSC 传输和 VHS 编码的实际原理，
  比 LUT+叠加层方案真实）；达芬奇也能做。

### 异形屏幕视频

按现场屏幕建平面 → 投影摄像机把视频投到平面 → 前后左右上下四个摄像机组分别输出；
进阶：单相机对齐 UV 一次出四个相机的画面，不用渲四遍。

## 4. Look_Dev（previz / layout）

- **previz** = 品质更高的 layout：模型动画比 layout 完善、带材质灯光，
  让导演看到接近最终的效果；国外有专门公司用 UE 实时做 previz。
- 国内叫法：**FLO（final layout）**——灯光来做叫 FLO，layout finaling 是 layout 部门做；
  现在绝大部分公司已换成 **Solaris + USD**（Pixar 还在用 Katana）。
- **LookDev 核心目标：让不同人员制作的不同资产在统一光照环境下有统一表现**。
  紧跟模型/贴图之后，用无颜色倾向的 HDRI 做调试、贴图标准化验证和纠错。
- 传统流程痛点：灯光环节等所有素材齐活才能开始，农场渲染最耗时，
  是动画电影里风险最大、暴露问题最频繁的环节——LookDev 把场景组装/灯光/材质/渲染
  抽象成独立迭代环节（工具代表：Katana、Clarisse）。
- 脚本插件文件夹里有 `ACEScg_ColorChecker2005.exr`，可用来匹配色彩。

### 灰球 / 银球（铬球）/ 色卡

- 银球（铬球）：反射环境，捕捉主光源位置、天花板色温、地面——三维据此真实布光。
- 灰球：看光线，提供光照和阴影数据。
- 片场有专人拍场景 HDR，**每几十分钟~1 小时重拍一次**（环境光会变）；同时拍色卡。
- 合成用途：CG 里用拍的环境 HDR 照明，渲标准灰银球+色卡，
  合成时把两边色卡对上（达芬奇等软件自带色卡对齐），球和色卡差不多了再开始调色——
  减少颜色误差。Houdini 自制灰银球+色卡的模型/材质设置截图见原笔记 QQ20251031 系列。
- 吐槽：部分导演懒得弄，合成全靠后期凭感觉——"合成看着假也不是没道理"。

### 大量道具的程序化 LookDev（案例）

- Blender 建模时用 `Material` 区分物件（所有墙身=墙壁材质，所有窗框=窗框材质）；
- 到 Houdini 后材质信息保留，据此整理分配物料；
- 用 **Triplanar（三维映射）** 做纹理映射，**免拆 UV**；
- 配合 **Curvature map（曲率贴图）** 和 **Dirt map（污垢图）** 做细节变化，
  资产更新也不怕；
- CG 材质尽量用**实拍照片混合**；跟拍时尽量拍照 + 照片扫描整个场景 + 拍灰银球色卡。

### 前期配套概念

- **Previs**：预览场景延伸/动作场面；用准确环境资料和真实摄影机数据做，方便各部门沟通。
- **Photogrammetry（摄影测绘/拍照建模）**：多角度拍照算 3D model，
  理解真实尺寸、辅助 Layout 和 Previs。

## 5. 畸变矫正工作

两种畸变：**枕形畸变**和**桶形畸变**（对照图见原笔记）。

### 总流程

`LensGrids`（拍棋盘格）→ `LensDistortion` 矫正并采集 UV 变形图（`UVMap`）→
`Shots` 所有素材经 UV 矫正（`STMap / UndistortShot`）→ 跟踪（`Matchmoving`）→
三维与渲染（`3DSystem / 3DRender`）→ 合成后把内容**变形回去**（`STMap / ReDistortShot`）→
最终合成（`Merge / FineShot`）。
没有棋盘格时，可对场景中的直线物体分析求解。

### 拍摄棋盘格（片场实操）

- 打印在坚硬哑光表面，避免弯曲/皱纹，要足够大覆盖整个相机视野。
- 夹具固定、保持水平（手机 App 检测）；**用拍摄特效内容的那台相机拍**；
  对齐方法：中心点居中，四周四点对十字。
- 打光照亮棋盘格，用焦点图辅助对焦到最清晰。
- **每个镜头放个打板写上焦段等信息**，避免后期不知道用什么镜头矫正的。
- 对着屏幕直接拍也行。棋盘格黑白即可；怕曝光问题可把白色改成灰度 **0.18**。
- 网格图资源：24liespersecond.com/VFX-Lens-Distortion-Grids（48"×96"，PDF 最清晰；
  原笔记本地存于 `畸变矫正网格图/` 文件夹：基础网格、嵌套小网格、晶状体分离网格、焦点图）。

### Nuke 畸变还原（节点级操作）

- **获得矫正数据**：`LensDistortion` 节点，`Solve Error < 1` 算好结果；
  改跟踪点细节前先关掉 `Analysis` 选项卡的 `Preview`；
  `Mode` 在 `Undistort（矫正后）` / `STMap（矫正前）` 间切换来检查对齐；
  `Lens Type`：`Spherical` 球面 / `Anamorphic` 变宽。
- **渲染 UV**：`Mode` 选渲染；通道选 `all`（或只渲 `motion`），
  **文件类型 EXR、32 bit float**；可写脚本渲完自动建 `Read` 节点。
- **还原（去畸变）**：
  1. `BlackOutside`：边缘拉伸去掉变黑边；
  2. `C_STMap`（GPU 加速），`Map` = `stmap → forward` 修复畸变；
  3. `Crop`：把屏幕扩出框外的数值填进 `box`，恢复无畸变尺寸。
- **畸变回套（redistort）**：
  1. `Reformat` 恢复原尺寸；
  2. `Transform` 移回原位置；
  3. `C_STMap`，`Map` = `stmap → backward` 应用畸变；
  4. `Crop` 点 `Reset` 恢复 bbox。

## 6. 合成工作（pipeline 视角）

### pre-comp（前期合成）

渲染后在 Nuke 里调 matte painting（遮罩绘画/绘景接景）：简单调色 +
按需叠加其他部门元素做 `slapcomp`，然后把 .nk 工程交合成部。

### 渲染真实感清单

1. 合适的焦段；
2. 跟高速移动物体时模拟摄影师"稍微没跟上"；
3. 相机抖动；
4. 镜头光斑、畸变；
5. 穿越机两类图传参考：模拟图传（延迟低，如俄乌战争画面）。

### 合成自检 7 问

1. 黑值白值、白平衡；
2. 跟踪匹配、运动曲线、运动速度（layout / matchmove）；
3. 虚焦匹配、运动模糊；
4. 阴影（投射阴影、接触阴影）；
5. 交互光（互动光）；
6. 2D 素材的比例大小、位置透视、色相亮度、半透问题；
7. 抠像融合、边缘问题、溢色问题。

### AOVs（任意输出变量）速查

EXR 最多 **1024 通道**，支持 16F/32F/32int（JPEG 3 通道、TGA 4、TIFF 5，所以行业用 EXR）。

| AOV | 用途 |
|---|---|
| Z（Depth） | 空气雾、景深；默认 raw 输出，Nuke 里 `Grade` normalize 后用 |
| albedo | 无光照纯色层，常配 AO |
| AO | 环境光遮蔽，叠接触阴影增体积感 |
| coat | 清漆层（第二层高光），釉瓷/车漆 |
| diffuse | 带光照的颜色层，无其他材质信息 |
| direct / indirect | 直接光照 / 光子反弹间接照明 |
| emission | 自发光提取 |
| motionvector | 后期运动模糊 |
| opacity | 透明材质控制 |
| specular | 高光强弱调节 |
| sss | 次表面散射 |
| Transmission | 折射（水、玻璃） |
| translucency | 半透明度 |

- 渲染器分层习惯：Mental Ray 按 Direct/Indirect/Ambient 分；
  Arnold 把 diffuse、specular 各分 direct/indirect。
- beauty = 各灯光层叠加（**想单独调就别用 beauty**，分层输出）。
- 遮罩类：`Shadow`（direct/indirect）、`Matte/ID`（RGB 分割物体）、
  `Alpha`、`Light Link`（指定灯光对指定物体的效果）。
- **信息层通常输出 32bit**：UV（Nuke `STMap` 调用）、Normal（Nuke relight 重打光）、
  Position（点云/VSOP 参照）、vector Displacement、Motion Vector、
  FacingRatio（表面点与相机夹角）、Deep（PRMan/3Delight/Mantra 可出，做 Deep Merge）。
- 效果层：`bloom/glow`（高光辉光区）、`volume scatter`（体积光，单分层渲、黑底）、
  皮肤 SSS 分 specular/front/mid/backscatter（合成用 `plus`）、毛发分顶端色/根部色/高光；
  **流体分层（泡沫/流体/置换水面可能不是一个软件做的）要先和后期特效师沟通**；
  渲染信息层（CPU 耗时）用于项目渲染时间预算。
- 合成算法：大多 `plus` 和 `multiply`，怎么调看合成师对画面的理解；
  自己用的话一个 Beauty + 单独遮罩/信息层就够。
- ST-Map：用 STMap 图校正镜头畸变，畸变模型沿节点树传到 Export 节点。

### PBR 核心（速记）

- PBR = 基于物理的光照 + 基于物理的材质；是一种方法而非硬标准。
  出现前是 Blinn-Phong：贴图固定、靠感觉调、换光就得重做。
- 两大工作流：**Metal/Roughness（最常用）** 与 **Specular/Glossiness**。
- 三大原理：微表面理论（微观无绝对光滑）、菲涅尔反射（入射角+材质决定反射；
  水面近看穿底、远看强反射）、能量守恒（出射光能量 ≤ 入射光）。
- 渲染方程要素：`Li` 入射光、`f` 反射函数（**BRDF**，半球积分）、`Le` 自发光 → `Lo`。
  漫反射常用 Lambertian BRDF；环境光用 IBL（Image Based Lighting）。
- **F0**（0° 菲涅尔反射）：非导体（电介质）普遍 **0.04（线性空间，4%）**，M/R 流程中
  通常锁死（可复写范围 0.0~0.08）；水 0.02。找不到 IOR 就先假设 F0=0.04。
- 常见反射值（线性空间）：非导体 2~5%（sRGB 约 40~75）；宝石 0.05~0.17；
  液体 0.02~0.04；原始金属 70~100%（sRGB 约 180~255）。

#### M/R 工作流贴图

| 贴图 | 要点 |
|---|---|
| Base Color (RGB, sRGB) | 含漫反射色+反射率色；比传统 Diffuse 平、对比度低（不带光影） |
| Metallic (灰度) | 遮罩：哪里是金属；原始金属灰阶约 235~255 sRGB；锈蚀/油漆按非金属 |
| Roughness (灰度) | 0.0 纯黑=光滑，1.0 纯白=粗糙；越糙高光越散 |
| 另配 AO / Normal / Height | 光影视差与置换 |

优势：F0 不易出错、灰度贴图缓存压力小、兼容性最广。
劣势：F0 固定 4%（多数实现可复写）、**低分辨率下白色边缘问题明显**。

#### S/G 工作流贴图

| 贴图 | 要点 |
|---|---|
| Diffuse (RGB, sRGB) | 只含非金属反照率；**纯黑 = 原始金属**（金属无漫反射） |
| Specular (RGB, sRGB) | 金属反射值 + 非导体 F0 都写在 RGB 里，**可自由调 F0** |
| Glossiness (灰度, Linear) | 0.0 黑=粗糙，1.0 白=平滑（与 Roughness 相反！） |

优势：边缘效应不明显、F0 可调。
劣势：F0 易填错打破能量守恒；多一张 RGB 贴图性能消耗大；
名词像传统流程但数据不同，要求设计师懂 PBR 理论。

#### 通用贴图

- AO：定义表面各点环境光暴露程度，后制加重夹角/交界面阴影。
- Height：做置换/视差映射，比法线、凹凸更真实。
- Normal：RGB = 法线 XYZ；保存高模细节映射到低模；Substance 可烘焙或由高度图转换。

### 传统光照模型（背景知识）

- Lambert：漫反射，Kd × 光强 × cos(N·L)（Max 防负）；平行光不考虑衰减；
  缺点侧面变暗 → 把夹角从 0-1  remap 到 0.5-1（半兰伯特）。
- Phong：只看视线和光线在法线两侧的情况；高光有断层。
- Blinn-Phong：用半程向量算高光（现行传统方案）。

## 7. 焦距 / 色彩空间

- 焦距 ↔ FOV 转换计算器：`desmos.com/calculator/yntecpwnu2`（焦距FOV1转换）。
- Maya 色彩空间配置：见原笔记 `图片/DCC/maya配置色彩空间.png` 两图
  （配置色彩空间 + 配置渲染视图）。
- 监视器是 DCI-P3 时，**所有软件的监视模式都设 `P3-D65`** 才准；
  `Display P3` 是显示器厂商的卖货增强，国际标准就是 DCI-P3 最好。
  `Display` 后缀代表监看环境。例：达芬奇输出色彩空间设 `P3 D65`，
  Nuke、Houdini 的监视器也要设 `P3 D65`。
- **视效交付四件套（用户现行标准）**：
  1. 文件格式：**OpenEXR (.exr)**——多层通道、多压缩算法、>10 档动态范围。
  2. 位深：**RGB Half (16-bit Float)**——约 30 档动态范围，超过最好摄影机；
     相比 32F 同视觉质量体积小 50%，Nuke/Houdini 读取和缓存更快。
  3. 压缩：**DWAA（Level 45）**——梦工厂的有损压缩，视觉无感，适合上云分发；
     高精度 Keying/denoise 的镜头换无损 PIZ 或 Zip。
  4. 色彩空间：**ACEScg (AP1) / Linear**——合成必须线性空间；
     ACEScg 专为 CG 渲染设计，避开 AP0 的虚色区。

## 易错点

1. 畸变工作流顺序搞反：必须**先去畸变→做跟踪/三维/渲染→合成后 redistort 回套**，
   直接在有畸变的画面上做 CG 会永远对不上边缘。
2. `LensDistortion` 的 `Mode` 忘了切：`Undistort` 是矫正后、`STMap` 是矫正前检查；
   渲染 UV 时必须用 EXR + 32F。
3. `C_STMap` 方向搞混：去畸变 `forward`、回套 `backward`；回套前记得 `Reformat` +
   `Transform` 复位，`Crop` 点 `Reset`。
4. 片场不打板记录焦段 → 后期不知道用什么镜头参数矫正；每镜头必打板。
5. S/G 流程里把 Glossiness 当 Roughness 用（黑白含义相反）；
   或给非金属 F0 乱赋值 → 打破能量守恒，渲染效果错误。
6. 用 beauty 层直接交合成 → 无法单独调灯；要单独调节就分层输出，信息层给 32bit。
7. 流体分层不沟通就渲 → 泡沫/流体/置换水面可能来自不同软件，先和后期对齐。
8. 监视器 DCI-P3 却在某软件里用 Display P3/sRGB 监看 → 全链路色彩不一致；
   达芬奇/Nuke/Houdini 要统一 `P3 D65`。
9. 口腔/头发/眼白死黑不修 → CG 反弹有限，张嘴镜头要主动提亮口腔内部。
10. 层次全靠加细节 → 细节精度做不到明暗虚实能做的层次；先分点线面、大中小、
    强中弱，再谈细节。
