# 鸽子飞行动画 48fps 文件备份

[下载工程 ZIP](Dove_Flight_FBX.zip) · [使用说明](使用说明.txt)

保存自本机 `outputs/dove-flight-polished`。ZIP 含三份 FBX、可编辑 HIP、预览及场景所需贴图和捕获几何，共 19 个文件。已核对 ZIP 每个成员与原文件的 SHA-256；摘要见 `manifest.json`。

这次仅归档既有文件，没有重新制作、冷开或评定动作质量；不宣称通过新的视觉验收。旧 24fps 文件备份仍在 `examples/dove-flight`。
