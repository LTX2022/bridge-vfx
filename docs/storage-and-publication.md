# 文件保留与 GitHub 范围

GitHub 保存当前维护源码、skill、接口文档、历史交接文字、选定验证摘要和工程示例。历史记录位于 [handover](../handover/README.md)；本次文件清单位于 [整理报告](../handover/final-storage-audit-20261113/README.md)。旧记录只描述各自时点的结果，不提升当前能力范围。

当前历史源码采用 [归档读取](history-archive.md)：登记到内容仓库的旧包和快照按需恢复原路径，空闲后回收展开缓存。早期清单中的文件数量是当时快照，不代表当前仍全部展开。

辅助缓存另行合并到 `outputs/Bridge-auxiliary-cache-archive-20261113`：9,036 个帮助与编译缓存文件去重存储，291 份 Finder 元数据合并备份后移除展开副本。原仿真帧、工程和受签依赖保持原用途，详见 [剩余文件整理与恢复验收](../handover/remaining-consolidation-20261113/README.md)。

本机 `outputs` 保留以下材料：

| 材料 | 保留原因 |
| --- | --- |
| 已登记工程依赖及旧插件版本 | 原路径身份保留；已迁入内容仓库的源码由归档入口恢复，其余依赖保持展开 |
| HIP、NK、EXR、缓存、原始输入和其他制作文件 | 保存原工程、失败现场、参考及可用局部成果 |
| 原始回执、配置、日志和数据库 | 保留来源、停止与预算事实，不能用 skill 总结替代 |
| 密钥、令牌、私有运行状态 | 仅本机保存，不进入 GitHub |
| 可恢复归档 | 收纳已退役测试环境和源码副本；原展开路径已删除，重放旧软件测试需先恢复 |

已退役副本没有并入当前插件运行时，也没有通过链接或硬链接共享受签文件。知识已提炼到 skill，原始证据按用途保留。GitHub 不是本机状态的完整备份，克隆仓库不能自动读取或继续全部历史任务。

工程示例见 [历史结果文件](../examples/historical-results/README.md)；鸽子工程的较新文件备份见 [48fps 版本](../examples/dove-flight-polished/README.md)。工程文件的复制与摘要核对不代表本轮做过原生制作或视觉验收。
