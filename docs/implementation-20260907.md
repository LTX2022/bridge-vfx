## 已落地的实现

- 执行底座：任务进程锁；模型回合稳定请求 ID；已完成动作跨状态重试读取原结果；未确定动作拒绝盲目重放。缓存下发前保存恢复意图，PARTIAL/CACHING 能进入宿主核对；错误 grant 不覆盖原恢复记录。
- 缓存宿主：独立只读 cache_status；结合执行前文件时间核对新产物；异步按钮失败持久化 FAILED；连接异常回到明确的恢复状态。
- 新场景守卫：TaskSpec 2.1 的 new/untitled 在缺少隔离场景所有权握手时明确 AWAITING_INPUT；运行时不将其误报 INTERNAL_ERROR，也不自动尝试修复。
- 工程和实例：TaskSpec 2.1 分别表达 HIP/NK 路径、哈希和实例身份；子任务使用所属软件的绑定；两个文件都进入冻结清单。新版宿主提供进程会话 UUID，后端重新发现实例时拒绝旧会话。
- 通信：Houdini 请求体大小和读取期限限制；主线程排队超时区分未执行取消与正在执行的不确定结果；Ramp 参数可以序列化。Nuke 增加认证、有限消息长度、会话身份和超时回调处理。
- 验收边界：修正证据序列化方法；域诊断与整包验收分开；整包入口不能通过缩小域集合降低门槛。
- 控制项：渲染参数不自动归为仿真修改；含不支持修改的候选整项拒绝。
- 参考顺序：有参考时先等待分析，核对分析哈希与参考哈希后再启动初始预览；保存的分析进入实际子任务。
