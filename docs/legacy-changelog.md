# Changelog

## 2.0.0-rc.1

- Added strict TaskSpec v2 contracts, versioned domain packs, component/stage DAGs, deterministic metrics, causal candidates, and SQLite pipeline state while retaining the v1 recipes.
- Added separate capability-probed vision and DeepSeek planner gateways with a single-action tool budget and no raw-media path into text-only planning.
- Added an ID-only SkillIR compiler/execution VM, provenance-first KnowledgeCard ledger, protocol-neutral DCC backends, and a fail-closed future SideFX MCP adapter.
- Added a mediated `DoubaoDesktopRoute` gateway and separate UI-control/Skill-conformance release contracts; DeepSeek and HY3 remain optional adapters rather than support gates.
- Added exact-subject Houdini simulation-cache approval, independent verified-experience promotion, HMAC host enforcement, grant invalidation, and restart-safe lineage.
- Added structured Houdini FX actions for all first-party domain manifests and a native Nuke reference-composite graph with recursive final-Write lineage auditing.
- Added the cross-DCC `vfx-pipeline` package, the progressive `vfx-visual-twin` Skill, positive release allowlists, support-claim verification, competitive research, and per-domain fault fixtures.
- All new domain packs remain experimental until H21/H22/Nuke17, real-reference, Doubao UI-control and per-domain Skill-conformance evidence is present; legacy v1 or optional-model evidence is not reused as v2 proof.

## 1.4.0-rc.2

- Added Houdini `123.py`/`456.py` idempotent startup hooks for new scenes and opened hip files.

- Added H21/H22 Karma CPU and Nuke 17 live-validation evidence with per-frame NDJSON progress.
- Added portable multi-Python plugin checks and cross-platform release-facing startup guidance.
