# GitHub 历史材料补充与本机核对

私有仓库 `LTX2022/bridge-vfx` 的 `main` 已补充历史材料索引、旧版 CLI 参考、14 个历史完成结果的 76 个文件副本，以及鸽子飞行动画正式 ZIP 副本。14 个结果文件由原结果记录核对 SHA-256；鸽子 ZIP 的 18 个成员均与本机对应文件摘要一致。原路径、签名和许可没有迁移。

鸽子 ZIP 大约 58.95 MiB，GitHub 接收成功但提示超过建议的 50 MB；不是 Git LFS。请按需留意仓库大小。

本轮仅删除源码目录下 29 个可重建 Python 字节码文件，共 954721 字节。`outputs`、旧安装、正式结果、票据、密钥和原账本没有因本轮清理而删除。569 个受保护文件核对摘要均不变。

安装入口在允许访问既有本机任务状态的条件下，9 个工程均可选择、14 个完成结果均读回 COMPLETE；原 V2 目标 FAIL、V3 PASS 保持；原生执行工具调用为零。详见 [读回结果](readback.json)。受限进程的部分读取失败保留为 [受限读回](restricted-readback.json)；同任务正常安装入口及完整本机访问复测通过，不能凭此断定受限错误的精确底层原因。

`outputs` 的 383 个一级条目中，376 个出现在此前整理清单中，另有 7 个后续新增条目，包括鸽子工程各阶段和历史读取修复包。目录约 15 万文件，包含私有密钥、令牌、数据库和 7 个超过 100 MB 的文件；本轮未逐一判定所有文件用途，也没有将全部有用材料或依赖上传。候选版本、不可公开素材与未核实依赖继续保留，不能将本仓库视为完整历史恢复备份。
