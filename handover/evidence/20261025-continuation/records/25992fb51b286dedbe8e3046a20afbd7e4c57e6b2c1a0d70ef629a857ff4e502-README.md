16 份卡片对应当前正式域合同，每域列出基础、反馈和故障恢复三个 case ID；软体和颗粒分别列分支。它们是操作检查表，未记录真实执行通过。

当前必需版本为 Houdini 21.0.631 主版、22.0.459 兼容版，以及 Nuke 17.0v1；Nuke单域不依赖Houdini。旧429期待保留原键，仅作显式兼容与历史对照。459新增期待由当前原生模块生成，并引用独立的55个HDA定义和支持原件；compiled／运行时模板、隐藏字段、实际writer及完整生命周期仍未验证。

当前 native_basis_status 为 UNRESOLVED：声明、静态模板及软件 API 替身不代表完整原生依据已核定。先按 handover/REMAINING.md 补齐具体缺口，再基于同版本原始依据核定此字段。不得只修改标签以绕过预检。

只读预检使用包内 tools/preflight_real_acceptance.py，需要操作者提供本地可信宿主配置及具体 scope。scope 必须包含真实确认的 task_root、case/domain、request_id、1–12 个明确帧、至多120秒、磁盘预算、content_version 和前后操作快照；缓存另需绑定授权。不得把示例或占位符当成确认。

预检不启动 DCC 或 FFmpeg；通过也不自动授予实际运行权限。M1 接收与具体作业授权后，按卡片执行并保留原始事实。WorkBuddy 桌面 HY3 使用项目级配置及用户选择的完全访问权限，不改全局配置；模型身份无证据保持 unknown。

两条组合另需共同组合器真实消费上游已登记产物：烟/火/粒子→渲染→Nuke，以及刚体/几何→材质/渲染→Nuke。独立生成的 EXR 只能用于明确的 Nuke 单域夹具。
