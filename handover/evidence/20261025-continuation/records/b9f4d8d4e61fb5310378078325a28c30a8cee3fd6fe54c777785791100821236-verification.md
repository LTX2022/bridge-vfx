# Verification and support status

A task result is acceptable only when required artifacts are present, non-empty, readable, fresh for this run, connected to the intended component lineage, and produced by an editable graph. The target issue's pack metrics must improve without violating protected dimensions, followed by artist confirmation.

For temporal issues, evaluate the declared frame set and motion evidence. Never claim recovered physical speed or dynamics from a single still.

Domain maturity is evidence-bound:

- `experimental`: implementation exists but contract evidence is incomplete.
- `contract-tested`: schemas, safety, and deterministic fixtures pass.
- `live-validated`: a matching DCC/model build produced machine-readable artifacts.
- `supported`: all declared versions and required real cases pass and are indexed.

Software tests or a successful bridge health check do not make a domain `supported`. Missing model credentials, a DCC license, a required node/parameter, or a real reference case remains an explicit release blocker.
