## 1. 跨 DCC 交接（最优先，与 Houdini/Nuke 工作流相关）

### 1.1 Blender 摄像机 → Nuke

- 使用自带的 **Alembic (.abc)** 导出摄像机；Nuke 端用**摄像机节点读取 abc**。
  （截图见原笔记：`摄像机导入Nuke.png`、`摄像机节点.png`）

### 1.2 修改器动画 → FBX 的缓存链（烘焙管线）

Blender 修改器动画不能直接用 FBX 带走，走"abc → mdd → fbx"三段缓存：

1. 导出 `.abc`，存储动画数据
2. 导入 `.abc`，生成网格序列缓存
3. 导出 `.mdd` 烘焙数据（用 `NewTek MDD format` 扩展插件）
4. 选中模型，**删掉所有修改器**，导入 `.mdd`，生成序列帧
5. 导出 `.fbx`

> 这条链路对 Houdini 同样适用：Houdini 直接读 abc 更稳，不需要 mdd 这一步。

### 1.3 导出带骨骼和动画的 FBX

- **不要勾选 `应用变换`**（截图见原笔记：`QQ20251210-171403.png`）
- 导入 FBX 骨骼问题**基本无解**：Better FBX 等插件只能"稍微能看"，
  因为 Blender 与 FBX 的骨骼系统差异太大，没有通解。
  - FBX 骨骼方向 -X 轴对齐 vs Blender 骨骼 Y 轴默认方向，需手动调整。

### 1.4 FBX vs glTF：为什么 FBX 在 Blender 里总是坑（用户长篇总结，压缩版）

| 维度 | FBX 的问题 | glTF 的优势 |
|---|---|---|
| 许可证 | Autodesk 专有 SDK 与 GPL 不兼容，Blender 只能逆向工程自研导出器 | Khronos 开放标准，官方级支持 |
| 材质 | 只支持 Blinn-Phong；Principled BSDF 被压缩成固定属性，SSS/各向异性丢失；法线切线空间可能错 | 直接映射 PBR 金属度/粗糙度字段 |
| 纹理 | 中文路径/特殊字符/长路径解析失败；"内嵌纹理"可能因缓存机制没真打包 | 强制 PNG/JPEG，二进制索引彻底规避路径问题 |
| 动画 | 强制烘焙为逐帧数据，体积膨胀、目标软件无法精编；根骨骼位移可能偏移 | 关键帧无损直出，NLA → 动画采样，Unity 无缝播放 |
| 骨骼 | 无法区分控制器骨骼与形变骨骼，导入 Unity/UE 出现多余控制节点 | 骨骼层级与蒙皮权重完整保留 |
| 版本 | 2011/2013/2020 各版本结构差异大，高版本文件低版本软件材质丢失/动画错误 | 单一 `.glb` 包含完整资源，加载比 FBX 快 3-5 倍 |

**结论（用户原话）**：跨平台/Web/游戏引擎协作**优先选 glTF**；
必须用 FBX 时装 **Better FBX** 插件（基于官方 SDK，支持材质节点映射和骨骼方向修正）。

> Houdini 侧对照：Houdini 的 FBX 导入同样对骨骼动画不友好，
> 角色动画交接一律走 abc / USD，FBX 只用于静态网格。

### 1.5 色彩空间：ACES 配置

- 简单方案：渲染属性 → 色彩管理 → 序列编辑器选 `ACES`。
- 完整方案：下载 [Blender-ACES-Config](https://github.com/Ginurx/Blender-ACES-Config)，
  批处理启动（`.bat`）：

```bat
set OCIO=D:\Programe Files\ACES\ACES-blender-colour-management-master\config.ocio
start "D:\Programe Files\Blender\blender_3.3\blender.exe"
```

- 第一行是 aces 配置文件路径，第二行是 blender 路径。
- 不行就用"辣椒分支"替换 `.\blender_3.3\3.3\datafiles\colormanagement` 内所有文件
  （有 `filmic`、`luts`、`config.ocio` 三个文件）。
- 用户原话："Blender 不怎么有对于 aces 好的支持"——
  **与 Houdini/Nuke 的 ACES/OCIO 管线对接时，Blender 是最弱一环，要优先验证色彩一致性。**

### 1.6 分层渲染 → 后期合成（Nuke）

- 导出格式必须选 **`OpenEXR MultiLayer`** 才能正确导出多图层序列。
- Cycles 下：视图层属性勾选通道（阴影/高光/反射等）→ 渲染预览可查各通道。
- 合成界面：新建 `文件输出` 节点 → 格式 `OpenEXR MultiLayer` → 选好输出路径 →
  `添加输入` 加到 10 个左右，把 `渲染层` 节点通道全部连上 → 渲染。
- **Cryptomatte 层**：视图层属性里开启（设置截图见原笔记）。
  Nuke 端用 Cryptomatte 节点直接取遮罩。

### 1.7 外部跟踪数据 → Blender

- **ae 跟踪导入 blender 插件**：[TrackerJack](https://www.lookae.com/trackerjack/)
- **竖屏跟踪环境不匹配**：别的跟踪软件导入后竖屏的点总是飘——
  把摄像机**传感器尺寸 ×1.8** 即可（截图见原笔记：`微信截图_20240430192451.png`）。
- 跟踪中立面代表墙壁，基面代表地板。

## 3. 渲染和照明

### 3.1 更快渲染（实测参数）

- **噪点阈值提高到 `0.02`**，同时减少样本数——画面略暗、小细节略糊；
  **保持噪点阈值不变、分辨率加倍**，细节就回来了。
- 体积雾：渲染设置里体积相关选项要勾选，"效果几乎不差"（截图见原笔记）。

### 3.2 Cycles 设备选择（优化大型场景）

- **Win 用户：不要勾 CPU，只勾 GPU**。
- `OptiX`：RTX 显卡（光追引擎）；`CUDA`：GTX 等无光追 N 卡；
  `HIP`：AMD；`oneAPI`：Intel；纯 CPU 选无；Mac 选 `Metal`。

### 3.3 灯光

- **人物伦勃朗光调皮肤**：真实大小人物次表面权重一般 `0.014`，
  次表面半径 `.48 .17 .11` ~ `.9 .3 .25`。
- **灯光朝向**：灯光加标准跟随（空对象）约束，一直朝空对象照明。
- **灯光排除**：选中灯光，在"灯光链接"下拖入只需被照射的物体。

### 3.4 渲染不出物体排查顺序

1. 物体属性可见性是否勾选
2. 物体材质
3. 物体是否在渲染层内
4. 渲染设置（项目/粒子系统/物体可见性）

还不行：拖动点位移很怪 → 旋转缩放问题 → **`Ctrl+A` 应用全部变换**。

### 3.5 只渲染模型部分区域

生成一片平面，用 **`可见性 → 阻隔`**（holdout）功能遮挡视野以下部分
（截图见原笔记：`QQ20251019-171038.png`）。

### 3.6 360 全景视频

- 分辨率 **2:1**，Cycles 渲染器，摄像机类型设为**全景**。
- 可开 `VR` 插件检查素材。

## 4. 摄像机

- `Aperture`/`F-Stop` 控制景深：F 值越小光圈越大景深越浅（`f1.2` 大光圈、`f2.8` 小光圈）。
- 小光圈图像更锐利但颜色略失真；大光圈色彩饱和度高但边缘模糊。
- **Dolly Camera Rig**（官方插件）：姿态模式控制相机运动，更好用的相机绑定。
- 旋焦、lan hubert 相机抖动工具、**Pro Lens V2.1**（真实镜头散景）、
  **Lens Sim**（真实光学数据：色差/暗角/变形镜头/焦点呼吸/散景形状）。

## 5. 材质

### 5.1 Principled BSDF 各通道一句话（用户版）

| 通道 | 作用 |
|---|---|
| 基础色 | 固有色/纹理机理（如木纹） |
| 次表面 | 光穿透半透效果：皮肤、蜡烛、树叶、玉石；**基础色与次表面颜色一致**，权重=透光度 |
| 金属度 | 默认 0；为 1 即金属；也可用来加强反射 |
| 粗糙度 | 0=高光清晰，越大越虚；贴图明度控制（白=1 最糙，黑=0 光滑） |
| 光泽(Sheen) | 类菲尼尔边缘亮度，模拟布料绒毛 |
| 清漆(Coat) | 表面整体罩一层高光（有凹凸高光不清时"打蜡"） |
| 透射 | 配合 IOR 和透射粗糙度做水/玻璃/水晶 |
| 自发光 | 自定义发光颜色和强度 |
| Alpha | 黑白贴图镂空（黑扣白留；PNG 透明底则透明部分扣掉） |
| 法向/凹凸/置换 | 黑白贴图黑凹白凸；**法向和凹凸是假凹凸（只在表面），置换是真凹凸（模型整体起伏）** |

### 5.2 SSS 体积感配方

`玻璃` 做外壳 + `体积材质` 填充做次表面散射 → 半透不透的阴影（截图见原笔记）。

### 5.3 背面剔除（材质设置）

- 摄像机剔除：**开启可让物体靠近摄像机的部分隐藏**（EEVEE/Cycles 设置截图见原笔记）。

### 5.4 烘焙（实测要点）

- 前提：模型有 **UV + 材质球**；材质球里新建 `图像纹理` 节点（新建图像，尺寸=贴图尺寸）。
- 选中模型和图像纹理节点，渲染器选 **Cycles**，选烘焙类型和是否受光照影响，按烘焙。
- **多个材质球**：每个材质球里都要建图像节点，**选中同一张待烘焙图像**，
  然后选中全部图像节点+全部模型+全部材质球再烘焙。
- 可降低采样；烘 `Diffuse`（色彩空间 **sRGB**）时若材质有金属值**必须关闭金属值**（否则全黑），
  烘粗糙度时再开；**粗糙度/法线贴图色彩空间选"非色彩"**。
- 金属度贴图可用 `自发光` 烘焙代替，再用 `RGB` 节点区分（金属=白，非金属=黑）。

**烘焙全黑排查**（用户个人实验）：

1. 场景无灯光/环境光——漫射烘焙可取消勾选光源影响，但要给光源
2. 法线反了——编辑模式全选面 `Ctrl+Shift+N` 反转 / `Shift+N` 重算
3. 场景物体遮挡（少见）
4. 烘焙完没及时保存图像，过一会变黑——存一下就好

## 6. 烟雾 / 流体 / 海洋

### 6.1 烟雾基本设置（Mantaflow 气体域）

1. 发射器（Plane）+ 流体框（Cube，烟雾作用范围）。
2. Cube：物理属性 → 流体 → 类型`域`，域类型`气体`，缓存类型`模块化`
   → 出现`烘培数据`选项。
3. 发射器：加粒子系统做出烟雾移动范围 → 缓存。
4. 发射器：物理属性 → 流体 → 类型`流`，流体类型`烟雾`，流动行为`流入`，
   流来源选`粒子系统`+对应粒子系统名。
5. 流体框 `烘培数据`；烟雾材质在流体框上加**体积材质**调参数。

- **消除烟雾精度不够出现的正方形**：截图见原笔记（`微信图片_20231013015418.png`）。

### 6.2 简易交互波浪（动态绘画）

1. 运动轨迹物体（正方形）+ 细分很多的平面（右键平滑着色）。
2. 平面：动态绘画 → 类型`画布` → 表面类型`波浪`，**速率 `0.4`**。
3. 运动物体：动态绘画 → 类型`笔刷`。
4. 不动柱子：做反射波纹设置（截图见原笔记）。
5. 水材质：可试 `玻璃 BSDF`。
- 下雨 = 2 片面片：一片雨滴粒子发射器 + 一片波浪。

### 6.3 海洋（洋面修改器）

- `分辨率`＝波浪细节；`时间`＝波浪运动；`空间尺寸`＝洋面尺寸；
  `波浪`参数＝尺寸/高度/翻滚；`泡沫`参数＝浪尖白水（white water）。
- **洋面缩裹**：平面细分+向下挤出，上方点打顶点组 → 缩裹修改器目标=洋面、顶点组=刚建的组
  → 关掉洋面可视即可。

### 6.4 水面材质 / 小流水

- 静态水面：BOX + 环境光 + 材质节点（截图见原笔记）；水面材质用**位置节点**控制水流方向。
- 水龙头小流水：`物体→快速效果→快速液体` → 摆好 Liquid Domain →
  水池用液体修改器类型`效果器`做碰撞物 → 发射小球用`流动`。

## 7. 粒子 / 毛发

### 7.1 粒子系统发射物体

1. 发射器（任意物体）→ 粒子属性加粒子系统
2. `渲染→渲染为` 改 `物体`；`实例物体` 选要发射的物体；`缩放` 调大小
3. 发射时间：`Number`（数量）、`起始帧/结束帧`、`生命周期`
4. 完整查看模拟：`缓存 → 烘焙所有动力学解算结果`；不满意先`清除所有烘培`再调
5. 旋转：勾选`旋转` → `坐标系轴向`选方向，`相位`=轴偏移；
   持续旋转动画：勾`动态`，`旋转→角速度` 的`轴向`+`量`（速度）
6. **坑**：用了角速度动画后，在修改器面板对粒子发射器`实例独立化`，
   物体会静止在独立化位置、动画丢失。

### 7.2 毛发

粒子系统勾 `毛发` → 再勾 `毛发动力学` → 播放时间线即得毛茸茸效果。

## 8. 几何节点

### 8.1 尘埃粒子（用户完整配方）

- 正方形撒点 → `噪波纹理` 驱动运动；噪波后 2 个节点分别控制**噪波位置**和**散布空间大小**。
- 用 `实例` 替换点，控制实例旋转/缩放。
- `组输入` 节点把参数暴露到外部修改器面板。
- 运动快慢：噪波纹理 `W` 参数输入 **`#frame/1500`**（数值越大运动越慢）。
- 随机旋转：`随机值` 节点输入 `pi`（数学 Π），记得调 `矢量旋转` 的 `角度`。
- 尘埃实例：贝塞尔曲线做细菌毛发（`几何数据→倒角→圆` 调深度控制粗细，分辨率开小省内存）；
  小石块=立方体+一次细分。
- **所有灰尘必须 `应用变换`**；单个太大就单独缩小再应用变换。
- `M` 编组，`实例` 中选该编组。

## 9. 角色 / 群集

### 9.1 Auto Rig Pro 绑定流程

1. 模型保持 **T-pose**，不带骨骼（或导入骨骼的静态姿势与模型一致）
2. 选中模型 → 创建骨骼 → 默认添加 5 个骨骼位置点
3. 校正点位，取消勾选 `Fingers` → `Go!`
4. `Match to Rig` → 骨骼绑定到模型，完成
5. 导入骨骼匹配动画：先匹配大小和姿态再匹配动画

### 9.2 手动简易绑定（小鸟案例）

1. 打 3 节骨骼，选小鸟再选骨骼绑父子级
2. 选骨骼再选小鸟进权重绘制模式，一根骨骼画一次
   （`Ctrl+左键` 切换查看各骨骼权重；新版可能 `Alt+左键`，Mac `Option`）
3. 开自动关键帧，移动物体自动记录

### 9.3 群集插件

- **Procedural Crowds**：程序性人群（用户评价"超级好用"）
- **People going places**：低模人群
- **fauna master pro**：动物群集（陆地/海洋/昆虫）

### 9.4 角色关节位置移动

同一网格内进雕刻模式，用 `pose` 笔刷弯曲。

## 11. 杂项技巧（压缩保留）

- **缩裹修改器做塑料膜**：外壳→细分→Shrinkwrap→offset→平滑着色→细分→实体化。
- **物体贴另一物体表面（晶格法，不变形）**：晶格包住物体，`W` 必须设 `1`，
  物体与晶格做晶格形变父子级（`Ctrl+P`），晶格加缩裹；不贴合=细分不够。
- **跟随路径约束**：物体不在曲线上=变换有问题 → 位置归零或 `Ctrl+A` 应用全部变换；
  `偏移量` K 帧控制位置；`固定位置` 限曲线长度内；`跟随曲线` 调 `前进轴`/`向上坐标轴`；
  `动画路径` 不 K 帧也有初始运动。
- **简易三渲二**：EEVEE + 渲染像素 64 + Freestyle（边缘粗细 3，只勾 Silhouette）+ 合成节点。
- **消除 UV 拉伸**：开"校正面属性"。
- **螺旋曲线**：装 Extra Curves 类插件 → `Archemedian`。
- **正片叠底**：Multiply，公式 `C=(A×B)÷255`；去白留黑半透明叠底。
- **做云（Cycles 体积配方）**：环境球 EXR 侧光 → 默认体积材质 → 预览采样 256 / 渲染 1024 →
  调大光程（透射/散射更多更亮）→ 体积步进减压 → 用光程深度控制外虚内实和各向异性
  （光程次数增加云变黑=乘方曲线非线性，黑处少而通透）。
- **物体运动延续**：选最后两个关键帧 `Shift+E` → `线性外插`；
  **不可逆，只能删关键帧重 K**。
- **置换生成场景**：置换修改器 → 新建纹理 → 选图片。
- **大场景优化五招**：GPU-only 渲染；重复模型放集合→`实例化到场景`；
  `精简`修改器减面并应用；4K/8K 贴图降分辨率+共享纹理；松散模型合并。
- **裸眼 3D 大屏**：拍场地反求建模 → 内容不出摄像机视图边界 → 自发光+图像纹理
  → **UV 投射修改器**（宽高比匹配输出，如 1920/1080=1.778；模型要给细分防变形）
  → 复制一份 UV 并取消"校正宽高比例"展开 → 几何节点`设置位置`接 UV 把模型展平
  → 新建**正交**摄像机，模型尺寸填分辨率，模型占满视角 → 调 `%` 放大渲染。
- **摆正模型**：编辑模式选向上的面建坐标轴 → 物体模式勾 `选项→变换：仅影响：原点`
  → `物体→变换→对齐到变换坐标系` → 取消勾选后右键`将多项重置为默认值`。
- **形态键**：物体数据属性加 2 个形态键 → 编辑模式变形 → 物体模式调`值`；
  **导出到别的软件不可用**。
- **Blender 合成器导出失败**：新建一个摄像机即可解决。
- **实体化修改器**：`Simple` 不适用边有 2 个以上相邻面；`Complex` 处理各种几何。
- **导入图片做平面**：开内置 `Import Images as Planes`；图片连自发光保持本色。
- **缝合边** = UV 边缘拆分开始的边。
- **雕刻**：开`动态拓扑`+对称径向数值拉高=同时雕多个对称位置。

## 易错点

1. **导出任何跨 DCC 资产前 `Ctrl+A` 应用全部变换**——跟随路径跑偏、拖动位移怪异、
   实例大小错误，九成都源于未应用变换；唯独**导出带骨骼动画的 FBX 时不要勾"应用变换"**。
2. **FBX 骨骼动画基本无解**（轴向差异 -X vs Y）；角色交接走 abc/USD，静态才用 FBX，
   游戏引擎优先 glTF。
3. **多通道 EXR 必须选 `OpenEXR MultiLayer`**，普通 EXR 只带一层。
4. 烘焙贴图色彩空间：Diffuse=sRGB，粗糙度/法线=**非色彩**；金属值开着烘 Diffuse 会全黑；
   烘焙完**立刻保存图像**，否则过一会变黑。
5. 色彩管理：Blender 的 ACES 支持最弱，跨 Houdini/Nuke 管线**先验证 OCIO 一致性**再开工。
6. 粒子系统调参前**先清缓存再烘焙**；`实例独立化` 会丢失角速度动画。
7. 晶格缩裹法 `W` 必须为 `1`，否则被吸附物体变形。
8. 竖屏跟踪点飘：传感器尺寸 ×1.8。
9. 形态键、Blender 内部修改器动画**离开 Blender 即失效**，必须走 abc/mdd 缓存链。
10. 形态键"物体运动延续"（线性外插）不可逆，用前三思。
