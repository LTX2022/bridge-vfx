## 1. 建模

### 1.1 AI 建模的两步本质

1. 从图片/视频识别物体**点云信息**（比传统照片建模快，且有推测扩展能力）
2. 完成**几何模型生成**——两步组合即可文生 3D。质量取决于训练数据的数量和精度。

行业判断：AI 资产生成让电影前期**预演/虚拟制片**成本极低，不必等资产齐全再讲戏。

### 1.2 倾斜摄影（Photogrammetry）标准流程

1. **拍摄**：固定焦距、小光圈大景深、纯色背景；物体居中占满画面，360° 环绕连贯拍摄
2. **RealityCapture (RC)** 对齐生成点云 → 纹理映射（截图见原笔记）
3. **优化**：RC 自带工具减面；自由设置 UV 数量与分辨率
4. **ZBrush (ZB)** 二次修复（RC 模型表面不平整是常态）
5. **Substance Painter (SP)** 重做材质、烘焙贴图（RC 只有简单颜色层）

### 1.3 扫描模型 Blender 清理七步

| 步骤 | 操作 |
|---|---|
| 整理焊接 | 全选 → 合并；加【焊接】修改器焊重叠顶点 → 应用 |
| 模型居中 | 原点设到几何中心；位置归零（侧边栏【条目】→【位置】） |
| 清理碎块 | 编辑模式按 `L` 选主体，`Ctrl+I` 反选，`X` 删除 |
| 切分模型 | 【网格】>【切分】画直线切割；或布尔修改器交集裁切 |
| 平滑表面 | 【平滑】修改器（可能损失贴图细节，需贴图模式反复对比） |
| 优化贴图 | 纹理绘制界面【克隆】工具（`Ctrl+左键` 取色，涂抹修复） |
| 模型减面 | 【精简】修改器调比例 → 应用 |

### 1.5 Digital Double（数字替身）五步走

1. `RealityScan` 扫描粗模
2. `Blender`/`ZBrush` 修复不平整面
3. 导回 `RealityScan` 重新做 UV 贴图投射（或别的软件还原 UV）
4. `Character Creator` + `Headshot 2` 插件重拓扑——自带完美骨骼标准人，面部和身体继承标准人绑定
5. `beeble` 分离光照信息与固有色，得到不受光照影响的贴图

> 关键认知：视频扫描建模会把现场高光阴影**烘进贴图**，漫反射贴图自带阴影变化——必须做去光照处理。

### 1.6 重拓扑 / AI 工具

- [AutoRemesher](https://github.com/huxingyi/autoremesher)：开源自动四边形重网格
- **Meta ShapeR**：SLAM 提供骨架和尺子（准确度）+ 实例分割提供剪影（独立性）+ VLM Caption 提供材质描述（细节）
- [ActionMesh](https://github.com/facebookresearch/actionmesh)：视频转动画网格，<1 分钟，需 32G 显存

## 2. 材质

### 2.1 一句话总纲

- **90% 的材质**：漫反射着色器 = 纹理 + 光泽（电介质）
- **10% 是金属**：不折射光线、没有漫反射，秘诀全在 **bump（划痕）和 roughness（污渍）** 两张贴图
- Glossy 做金属会有折射假象；metal 是全反射

### 2.2 PBR 两大工作流

| | Metal/Roughness | Specular/Glossiness |
|---|---|---|
| 基础纹理 | Base Color、Roughness、Metallic | Diffuse、Glossiness、Specular |
| 通用纹理（Common Maps） | AO、Normal、Height（两派相同） | 同左 |

宏观上 **Base Color == Albedo == Diffuse**，都是一张 RGB 纹理。

贴图通道颜色约定：凹凸 = 黑白；法线 = RGB 颜色；置换 = 黑白。

### 2.3 贴图术语速查

- `Albedo`：纹素级表面颜色/基础反射率；颜色属性纯白时不影响贴图，其他颜色则叠加
- `Metallic`：灰白图，越白金属度越强
- `Normal Map`：只改表面光照结果，不改几何
- `Parallax mapping`：NormalMapping 增强算法；法线贴图 Alpha 通道存 HeightMap（饱和度记录高度）
- `Displacement mapping`：真正改变几何表面（需 ShaderModel 3.0+）
- `Occlusion` (AO)：灰白图，增强阴影深度与细节
- `Detail Mask`：配合 Detail Albedo/Normal 次贴图，屏蔽不需要细节平铺的区域
- `OpenGL vs DirectX 法线`：绿通道方向相反（截图见原笔记）

### 2.4 IOR 折射率表（实测值，最高价值）

记忆锚点：**水 1.33 / 冰 1.31 / 玻璃 1.5 / 水晶 2.0 / 钻石 2.42**

| 材质 | IOR | 材质 | IOR |
|---|---|---|---|
| 空气 | 1.000 | 有机玻璃/亚克力 | 1.490–1.492 |
| 水 (35°C) | 1.325 | 玻璃 | 1.500 |
| 冰 | 1.309 | 耐热玻璃 | 1.474 |
| 酒精 | 1.360 | 塑料 | 1.460 |
| 牛奶 | 1.350 | 尼龙 | 1.530 |
| 铝 | 1.390–1.440 | 珍珠 | 1.530–1.690 |
| 铜 | 1.100–2.430 | 象牙 | 1.540 |
| 金 | 0.470 | 翡翠 | 1.560–1.605 |
| 铁 | 2.950 | 水晶/石英 | 2.000 |
| 钛 | 2.160 | 钻石 | 2.418 |
| 铅 | 2.010 | 沥青 | 1.635 |

金属 IOR 曲线几乎一致，非金属亦然；IOR 在反射里 = 反射衰减强弱，在折射里 = 透明物体折射率。

### 2.5 次表面散射（SSS）

光线进入材质内部再从不同位置射出。皮肤/蜡/大理石/水果的柔和光感来源——**没有 SSS，CGI 皮肤像塑料**。

三个核心参数：散射**半径**（光散布深度）、散射**颜色**（透出后的色）、**尺寸**（内部传播距离）。
皮肤要微妙；水果可加深。金属、石材**没有** SSS，别加。

### 2.6 菲涅尔（Fresnel）

反射强度随观察角度变化。金属/水面可强化；硬质不透明材质过度使用会失真。
灯光侧应用：菲涅尔配合 normal 或 pref 层做**边缘辅助光**过渡。

## 3. 灯光

### 3.1 灯光类型六分法

| 类型 | 作用 |
|---|---|
| 主光 | 主要光源，塑形、区分主体与背景 |
| 补光 | 填补阴影 |
| 环境光 | 自然场景可见光，带来生命力 |
| 辅光 | 填充暗部 |
| 效果灯 | 特定场合（枪口火光等） |
| 边缘辅助光 | 边缘过渡柔化（菲涅尔 + normal/pref 层） |

**连续性原则**：镜头内灯光为故事和气氛服务；镜头连续时灯光需物理一致（可微弱变化）；切镜后可以不连续。**灯光为故事服务，可自由发挥**。遵循平方反比定律。

### 3.2 人像布光位速查

| 光位 | 效果 |
|---|---|
| 顺光 | 展示产品 |
| 蝴蝶光/美人光 | 摄像机上方打下，鼻翼蝴蝶阴影，显美 |
| 伦勃朗光 | 正侧 45°，鼻边小三角光区，显立体 |
| 侧光 | 正侧面，深邃神秘感 |
| 侧逆光 | 背后侧 45°，勾勒边缘、分离背景、加层次 |
| 顶光 | 神圣感（但显老，见下） |
| 逆光 | 人物背后，强感、神秘感 |

### 3.3 人脸修饰口诀（实测技巧）

**变年轻**：
- 高光打鼻梁和额头区域（光当化妆品），或削减侧光让脸显小
- 瑕疵正上方打光 → 瑕疵消失
- 灯靠近眼睛 → 人物更亲和
- 柔光减少皱纹；**灯光集中在有皱纹处**才能柔化肌肤
- **书式布光**：反光板 + 柔光布成夹角如打开的书，灯约 45° 斜打反光板，靠板布间距控制柔和度

**变沧桑**：顶光突显每道褶皱（最不讨喜）；下方小电池灯补面 + 聚光灯打背后墙壁 → 严峻可怕。

### 3.4 光比（实测公式，最高价值）

- 光比 = 主光 / 副光（入射光照度比；画面反推的是反射光强度）
- 测量选**颜色和反光率相同**的区域（如同一人面部两侧皮肤），避开油亮反光
- 皮肤纹理不均时，分析软件里加**高斯模糊节点**平滑数据再读数
- 由阴影方向、轮廓光位置可反推光质和光位

**Rec.709 ↔ 线性转换公式**（Excel 写法，实测可用）：

```
IF(B2>=0.081248, ((B2+0.099)/1.099)^(1/0.45), B2/4.5)
```

- 值 < 0.081248 → 除以 4.5
- 值 ≥ 0.081248 → 加 0.099，除 1.099，再开 2.2222 次方（1/0.45 ≈ 2.2222）

**IRE**（Institute of Radio Engineers）：视频信号亮度单位，常用 709 IRE 标定画面亮度。

## 4. 动作/动画

### 4.1 AI 动画两条主路径

1. **基础动画识别生成与预处理**（CV 姿势识别）——解放动画师从重复劳动到创意精修；预演阶段够用但还粗糙
2. **加速动力学模拟与解算**——AI 训练完成复杂动作/路径/交互动画；游戏动画探索比影视前沿，正强交汇

工具：Maya **MotionMaker**；动捕网站 move.ai / Kinetix / plask.ai；288 小时开源 MoCap 数据集（bones.studio）；虚拟人物 meshcapade。

### 4.2 Houdini 新动画工具（与 houdini-bridge 直接相关）

- `Selection set HUD`：选择集 + 显示组 + 频道组；固定选择集可确保对所有内容 K 帧
- 易失性热键 `Ctrl+Shift`：围绕任意轴心旋转/平移控件；按住 `B` 出径向菜单选定位器
- `velcro` 约束系统
- `动力学` 动画：设置起跳/着陆接触点 → 自动算出物理精确的路径和时间
- `布娃娃`（Ragdoll）：简单设置即得复杂物理运动
- `APEX`：纯数据驱动绑定——场景中一切（含动画曲线）转几何体存储；轻量高性能实时可编程图引擎

## 易错点

1. **扫描贴图自带光影**：视频/照片扫描会把现场高光阴影烘进漫反射贴图，直接用会在新灯光下穿帮——必须用 beeble 类工具分离光照与固有色。
2. **Glossy 冒充金属**：Glossy 着色器做金属会有折射假象；金属真实感靠 roughness + bump，不是靠反射强度硬拉。
3. **Normal Map 两派混用**：OpenGL 与 DirectX 法线绿通道方向相反，跨软件（SP↔引擎/渲染器）必须确认约定，否则凹凸反向。
4. **SSS 乱加**：金属、石材没有 SSS；皮肤 SSS 过重会像蜡像。硬质材质慎用菲涅尔强化。
5. **顶光陷阱**：顶光显老显沧桑，想"神圣感"才用；给演员减龄要反着来（柔光 + 瑕疵正上方补光）。
6. **光比测量污染**：测反射光时必须选同材质区域、避开油亮高光，否则光比数据被高光污染；数值波动大就先高斯模糊再读。
7. **709/线性混淆**：光比基于线性亮度计算，从 709 画面取值必须先转线性（0.081248 阈值公式），直接拿 709 值算光比全错。
8. **ZB 笔刷拖拽来源**：自定义笔刷只能从上方笔刷栏拖出，灯箱里拖不出来——自定义 UI 失败多半是这个原因。
9. **RC 模型直接进生产**：RealityCapture 输出只有简单颜色层且表面有瑕疵，必须 ZB 修型 + SP 重烘材质，不可跳过。
