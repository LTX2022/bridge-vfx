## 剩余文件的用途

剩余内容主要是原工程、仿真／渲染产物、输入、签名回执、停止与预算记录、数据库、密钥和任务状态，以及与这些状态混放的历史控制文件。原位保留这些材料，不能用知识总结或相同内容的新文件替代原路径身份。当前约有 23,318 份 JSON、3,977 个 `.sc`、1,251 个 HIP、1,076 个 EXR；扩展名只用于清点，不作为删除依据。

两处额外快照保留原样，共 381 个文件：一处原冻结成员均匹配，但多出 26 个 Python 字节码缓存；另一处是缺少对应根目录冻结清单的局部恢复源码。另有 36 处快照目录已无普通文件，保留路径。它们没有被冒充为本次清单一致的归档。含密钥、数据库或活动状态的整目录也未批量压缩或删除。

读取验收覆盖当前 macOS 的默认登记目录；本轮未做新的 DCC 冷开、渲染、视觉、跨平台或任意独立目录验收。当前正在产生文件的鸽子工程未参与清理，数量可能继续变化。

## 维护与恢复

- 主源码按 [历史源码归档读取](../../docs/history-archive.md) 维护。内容数据库与目录必须成对保留，不能当缓存清除。
- 辅助缓存及 Finder 元数据恢复说明在本机 `outputs/Bridge-auxiliary-cache-archive-20261113/README.md`。
- 旧 0.4.25 仅能与其回滚归档配套，不能直接指向新目录摘要使用。操作前停止查询连接、恢复当前全部原路径并核对摘要。
- GitHub 保存实现、当前说明和选定摘要；内容仓库、原始状态、详细逐文件清单与完整查询回执留本机。

主要摘要：`acceptance-summary.json`、`installed-readback-summary.json`、`source-store-build.json`、`source-roundtrip.json`、`cache-roundtrip.json`、`storage-final.json`、`protected-files.json`。完整本机查询记录为 `installed-readback.json`。
