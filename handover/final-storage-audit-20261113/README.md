# 文件整理、保留与历史读取核对

## 处置范围

覆盖当前 `outputs` 的 384 个一级条目，并对全部剩余文件登记保留类别。此前 376 个条目的工程记录与知识来源沿用已完成的整理清单；新增 8 个条目分别为鸽子参考及五个制作阶段、历史读取修复包、退役归档。参考和旧制作阶段保留本机；较新的鸽子 48fps ZIP 另存入 GitHub 示例，未将其标为本轮视觉验收通过。

逐文件清单不等于逐行审阅每份历史日志。清理依据是既有案例审查、实际依赖、明确的软件测试配置、可重建缓存标识、完整归档及删除前复核。原生冻结、失败记录、原素材、正式结果、签名和密钥保持原用途。

## 剩余文件为什么保留

- 当前工程目录、任务状态和安装配置展开得到 3,101 份 JSON、24,677 条引用；登记工程依赖保留原路径。
- 49 份旧插件展开包与各自 ZIP 的文件集合及字节一致；其中 48 份存在原路径引用，只退役 1 份。受签源码没有用符号链接或硬链接替代。
- 原始工程、输入、局部产物及失败现场用于继续工作或复查。正式结果中选定文件已有 GitHub 副本，不能因此删除原位置。
- 历史实现与记录用于解释旧回执、版本和失败条件。当前没有证明可以让全部旧签名统一依赖一个新版运行时，因此未改写旧许可或迁移这些依赖。
- 私有身份、数据库、宿主配置及原始回执留在本机。GitHub 保存整理后的文字与选定摘要，不包含完整私有执行状态。

各一级条目的数量、类别及既有审查来源见 `remaining-directories.json`；逐文件类别见本机 `remaining-files.json.gz`。以上是保留决定，不代表每个文件都用于当前版本；没有通过删除记录来减少历史失败或长期未完成范围。

## 核对结果

- 103,870 个未选中删除的文件核对无缺失。其间一份 `hserver.log` 和两份 `configured-houdini-binding.json` 内容变化；清理脚本没有写入这三份文件，不能宣称整个工作区完全不变。路径单列于 `preservation-verification.json`。
- 旧安装和选定正式记录的 569 项保护文件 SHA-256 全部不变。
- 新安装消费者正常选择 9 个工程，读回 14 个完成结果，全部 COMPLETE；原门架三版 PASS/FAIL/PASS 与无目标评估记录的 UNKNOWN 保留。原生执行工具调用为 0。摘要见 `readback-summary.json`，完整回执留在本机 `readback.json`。
- 当前维护源码与 GitHub 逐文件比较，除文档增量外保持一致；本机编译的 `tools/doubao/doubao_ax_helper` 是可由现有源码构建的忽略项，保留本机、不上传二进制。

## GitHub 与本机的分工

GitHub 保存源码、skill、接口文档、历史交接 Markdown、旧交付说明和选定核对摘要，以及原历史工程示例和鸽子工程文件备份。原始日志、数据库、许可、密钥、未登记实验和退役恢复归档留本机，完整依赖不作跨机器可移植承诺。

当前能力边界仍以根 README 为准：任意教程自主复现、全域及跨平台稳定制作尚未验收。本次完成的是文件处置和读取核对，不是新的制作能力验证。
